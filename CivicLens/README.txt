CivicLens Prototype - SIH25031

How to run:
1. Extract the ZIP.
2. Open the CivicLens folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Demo:
   - Citizen: login with citizen@demo.com / any password
   - Officer: officer@demo.com / any password
   - Admin: admin@demo.com / any password
5. Report an issue to see AI analysis, GPS capture, complaint ID and tracking.

This is a frontend prototype. Firebase, real AI API and production authentication are not connected yet.
